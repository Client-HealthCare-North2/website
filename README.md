# website
This repository is for our clients @ HeathlCare North

Here is the branching strategy we will follow for our repository and some good practice to consider:

GITHUB-Flow:

* We have one Master (or main) branch and developers will be using a feature (or release) branch to propose change to the website.

* One developer raises a pull request and it has to be approve by authorised team members to be able to merge into the main branch.

* Once your change are deploy to main, you are free to delete your feature branch to avoid any confusion. (it is safe to do so)

* When you want to work on another feature, It is encourage to create a new branch, make the change you want and merge them into main after approval from authorised team members
